WHAT WAS BUILT
--------------
record_run7.py   Records demo seeds 0-49 with the scripted expert, 96 px front + wrist
                 cameras as LeRobot video (use_videos=True, AV1, the repo's settings),
                 the 15-D observation.state, and the action [target_x, target_y,
                 target_z, target_yaw, gripper] read from env.target_pose() after the
                 expert's step. It reuses the repo's LeRobotWriter and make_frame
                 unchanged and swaps only the action feature, by replacing
                 lerobot_writer.build_features inside this process (the tracked file
                 is untouched). The video path worked first try (44.2 s for 50
                 episodes, so no lossless fallback was needed).
                 Check: 50/50 expert successes, 5513 frames. observation.state is
                 bit-identical (max |diff| 0.0) to datasets/pickplace_scripted_50
                 (run 2's data), so only the action column differs.
../verify_replay.py (now takes --abs-root/--delta-root/--out)
                 Replays the absolute actions through AbsoluteTargetWrapper on all 50
                 seeds: 50/50 succeed, every episode the recorded length, and the
                 converted delta matches the expert's recorded delta to 2.3e-6
                 (results/replay_abs_wrapper.json).
act_cpu_v7_abs.yaml  Run 2's config (act_cpu_v2.yaml): dim_model 256, 2 encoder / 1
                 decoder layers, chunk 20, n_action_steps 10, lr 1e-4, backbone lr
                 1e-4, use_vae false, batch 8, seed 1000. input_features =
                 observation.state + both 96 px cameras. normalization_mapping is the
                 default (VISUAL/STATE/ACTION MEAN_STD). 6000 steps, save_freq 2000.
diagnose_swap.py The repo-style open-loop image-swap test (scripts/diagnose_openloop.py
                 logic), using the repo's ACTPolicyAdapter unchanged.
eval_run7.py     Repo ACTPolicyAdapter (unchanged) + PandaPickPlaceEnv(image_size=96)
                 wrapped in AbsoluteTargetWrapper (../priv_common.py), run through
                 the repo harness (run_condition/summarize/write_csv) and taxonomy.
run_post.sh      Diagnostics on 2k/4k/6k, then nominal dev eval of 4k and 6k, then
                 demo and shifted eval of the best checkpoint. The best-checkpoint
                 rule was fixed before any result: more nominal dev successes wins,
                 and a tie goes to 6k.

IMAGE-SWAP SENSITIVITY (results/swap_sensitivity.json)
------------------------------------------------------
Setup: frame 2 of the first 20 training episodes. Episode 0's state is kept and the other
episodes' front + wrist images are swapped in. "delta" = the normalised [-1, 1] delta
the wrapper would send (current target = the dataset's action at frame 1), the same
scale as the repo's delta runs. A delta change can exceed 1 because each delta lies in
[-1, 1]. The repo's pre-registered pass criterion is a change >= 0.1 and a std >= 0.1
in x or yaw.

INTERPRETATION
--------------
- The action representation was the blocker. With the same images, state, network,
  optimiser and budget, absolute targets turn 0/100 into 31/50. The policy's approach
  outputs now depend on the images (swap test passes at every checkpoint), which run 2
  and runs 4-5 never achieved.
- The policy is still improving: 24 % at 4k, 62 % at 6k, with loss still falling. At 4k
  most failures are grasp_missed (25/50), i.e. it reaches but mis-aligns the grasp. At
  6k grasp_missed drops to 11. More steps look worthwhile (the run is only 8.7 epochs).
- Shifted cube box: 22 % (11/50), with 35/50 never_reached. With the cube's start
  box moved by (+8, -8) cm, the policy mostly fails to reach the cube, consistent with
  it not extrapolating outside the 50-demo training box (about 22 % of the shifted box
  overlaps the training box). The paired nominal-vs-shifted drop, 62 % -> 22 %, is now
  measurable because there is a nominal success to lose.
- Demo seeds 0-9: 7/10, about the same as the dev rate, so there is no sign of
  memorisation beyond what 10 trials can show.
